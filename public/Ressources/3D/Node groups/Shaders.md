# Shader editor node groups
## b3dSDF
Lien : https://github.com/williamchange/b3dsdf

Le plus utile que je connais est b3dSDF, un ensemble de node groups créé par William Change (CMZW) et disponible gratuitement sur Github. Il permet d'avoir accès à plein de primitives (formes de base) et à plein d'opérateurs qui vont intéragir avec ces primitives pour pouvoir créer des motifs procéduraux très poussés.
Il y a d'autres outils inclus dans le toolset, comme des opérateurs de vecteurs.

**Pour s'en servir, il faut juste télécharger le .blend sur le repo Github et le lier à votre asset library Blender.**
